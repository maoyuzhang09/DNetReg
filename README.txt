README - R code for DNetReg
July 2024


The downloaded file 'DNetReg.R' has the main function of DNetReg, EdgeReg and DEdgeReg.  An example of the simulation in the paper is included in the 'DNetReg_example.R' file.

The downloaded file 'model1_main.R' has the main function of DNetReg with time-varying covariates introduced in Section S1 of the supplement. An example of the simulation in the paper is included in the 'model1_example.R' file.


The downloaded file 'model2_main.R' has the main function of DNetReg with low rank and sparse covariate effects introduced in Section S2 of the supplement. An example of the simulation in the paper is included in the 'model2_example.R' file.
